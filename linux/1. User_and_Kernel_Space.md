# User Space and Kernel Space in Linux

Linux works in two areas called **user space** and **kernel space**. This design keeps your computer safe and running smoothly.

## Diagram

```plaintext
                +-------------------------------------------+
                |               User Space                |
                |-------------------------------------------|
                |  Applications, Libraries, Shells         |
                |  (word processors, browsers, etc.)        |
                +-------------------------------------------+
                              │
                              │   System Calls
                              ▼
                +-------------------------------------------+
                |             Kernel Space                |
                |            (System Space)               |
                |-------------------------------------------|
                |  Core Kernel, Device Drivers,             |
                |  Memory Management, Scheduling            |
                +-------------------------------------------+
                              │
                              │   Direct Hardware Access
                              ▼
                +--------------------------------------------+
                |                Hardware                  |
                |  (CPU, Memory, Storage, I/O Devices)        |
                +--------------------------------------------+
```
## User Space

- **What is it?**  
  It’s the area where all your apps (like browsers, games, or text editors) run. Think of it as your personal space for everyday tasks.

- **How does it work?**  
  - Apps in user space can’t directly access hardware like your CPU or memory.  
  - If something goes wrong with an app, it won’t crash the entire system.

---

## Kernel Space

- **What is it?**  
  This is the core part of Linux called the kernel. It controls your hardware and makes everything work together.

- **How does it work?**  
  - The kernel can directly talk to hardware like your CPU, memory, or disks.  
  - It manages important things like running apps, managing memory, and talking to hardware.  
  - If there’s an issue here, it could affect the entire system, so it’s carefully protected.

---

## How They Work Together

- **System Calls:**  
  Apps in user space need help from the kernel when they want to do something important, like saving a file or using the internet. They send a request called a *system call*.  
  Example: A text editor asks the kernel to save your document to the disk.

- **Safety:**  
  User space and kernel space are kept separate to make sure apps can’t mess up the core system. This way, Linux stays secure and stable.

---

This setup helps Linux run quickly and safely while letting apps do their jobs without interfering with the core system.
				


**Context Switching:**  
When a system call is made, the CPU switches from **user mode** (limited privileges) to **kernel mode** (full system access). Once the operation is completed in system space, control is returned back to user space. This switch is seamless and fundamental to maintaining the balance between user actions and system security.
